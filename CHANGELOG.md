## [0.18.0] - 2026-10-03

### Добавлено
- Голосовые сообщения записываются в формате OGG/Opus (родной для Telegram) с фоллбеками WebM/Opus, WebM, MP4
- Правильная очистка после отправки/отмены голосового сообщения: UI возвращается к текстовому вводу, таймеры и стримы освобождаются
- Локально отредактированные имена контактов (firstName/lastName в IndexedDB) теперь отображаются в шапке чата и сайдбаре вместо имён из списка чатов
- Новые опциональные поля `firstName`/`lastName` в типе `Conversation`

### Изменено
- Переключатели уведомлений по чатам скрыты (закомментированы с `// TODO:`) — GREEN-API не поддерживает per-chat notification state
- Унифицирована система мута уведомлений через `mutedChats.ts` (localStorage) в меню шапки, бейдже сайдбара и панели информации
- Голосовой рекордер предпочитает `audio/ogg;codecs=opus` с автоматическим перебором фоллбеков

### Исправлено
- Обработчик `onstop` голосового рекордера теперь корректно сбрасывает статус, очищает чанки/пики/накопленное время, освобождает стрим и плейбек
- Событие `track ended` больше не останавливает рекордер мгновенно (ломало запись с монитора)
- AudioContext возобновляется при suspended для корректной работы анализа формы волны

## [0.14.0] - 2026-10-03

### Добавлено
- Пароль приложения (`APP_PASSWORD`) с HttpOnly HMAC-подписанной cookie-сессией (24ч)
- Отдельный пароль для записи (`WRITE_PASSWORD`, по умолчанию равен `APP_PASSWORD`) и режим только чтения (`APP_ALLOW_WRITES=false`)
- Мутирующие методы требуют грант на запись; 403 без него
- Счётчик неудачных входов: 5 попыток → блокировка на 5 минут
- Серверный прокси GREEN-API: токен инстанса никогда не попадает в браузер
- Валидация Origin, лимиты тела/ответа (1МБ/8МБ), без проброса upstream cookie/CORS

### Изменено
- Эндпоинт `/api/auth` для управления сессией и грантом записи
- Dev-сервер запускает те же `api/` обработчики, что и прод (гейт, квоты, лимиты)

## [0.9.0] - 2026-10-03

### Добавлено
- Рефакторинг на feature-based структуру (`features/`, `widgets/`, `entities/`, `shared/`)
- Хук страницы чата разбит на фокусированные модули:
  - `useChatList` — состояние списка и фоновый проход превью
  - `useChatHistory` — постраничная история, слияние кэша, опрос раз в 15с
  - `useHistoryCache` — IndexedDB чтение/запись (store `profiles`, ключ `history:${chatId}`)
  - `useChatSelection` — выбор чата, back/forward, карточка контакта, архив, мут
  - `useChatCommands` — отправка, пересылка, удаление, загрузка файлов
  - `useMessageWall` — скролл, прилипание к низу, даты сверху, sentinel, IntersectionObserver пагинация
  - `useOlderPages` — батчевая загрузка старых страниц
  - `useInfoPanel` — вкладки, производные значения; `useContactDetails` — запрос карточки контакта
  - `useChatUiStore` — мобильное состояние чата (Zustand)

### Изменено
- Шапка разделена на навигацию, поисковое поле, меню
- IndexedDB-кэш вынесен в отдельный хук
- Запрос карточки контакта вынесен в отдельный хук
- Observer старых страниц вынесен в отдельный хук
- Введены абсолютные импорты
